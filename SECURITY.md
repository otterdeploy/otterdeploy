# Security Policy

## Project status

Otterdeploy is pre-1.0 and under active development. No supported-version or long-term-support
schedule is currently published.

## Reporting a vulnerability

Do not disclose suspected vulnerability details in a public issue, discussion, or pull request.

If GitHub offers a **Report a vulnerability** button for this repository, use that private form. If
it does not, open a public issue titled **Security contact request** containing no vulnerability
details, proof of concept, secrets, or personal data, and ask the maintainers for a preferred
private contact. The issue is only a request to establish a private channel; it is not the
vulnerability report.

For non-sensitive bugs, use the [normal issue tracker](https://github.com/otterdeploy/otterdeploy/issues).
